You reached this through an alias

The address was /docs/readme.html. There is no docs directory anywhere on disk. The location block reads:

location /docs/ {
    alias ./www/documents;
}

alias replaces the part of the path that matched the location prefix, so /docs/readme.html became ./www/documents/readme.html. Had the block used root instead, the whole path would have been appended and the server would have looked for ./www/documents/docs/readme.html, which does not exist.

That difference is the most common source of confusion in nginx configuration, and it is worth being able to state precisely: root appends the request path to the root, alias substitutes for the matched prefix.

The stylesheet on this page is loaded from /files/style.css, which is a second request through a different location block. If the server were guessing media types from content rather than extension, that request would come back as plain text and this page would be unstyled.

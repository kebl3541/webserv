This directory has no index.html, so the server generates the listing you came
through. That is the autoindex directive in conf/default.conf.

Every file here has a different extension, and each one is served with the
media type that extension maps to. Fetch any of them with headers shown:

    curl -i http://localhost:8080/files/style.css

and the Content-Type will be text/css, not text/plain.

That distinction is the whole point of this directory. The first version of
this server guessed content types by sniffing the first few bytes of a file.
Sniffing cannot tell CSS from JavaScript from a plain text file, because all
three are just text, so stylesheets went out as text/plain and browsers with
strict MIME checking refused to apply them. Types come from an extension table
now, which is what every real server does.

The PNG here was generated by a short script rather than downloaded, so the
repository carries no binary whose provenance cannot be checked.

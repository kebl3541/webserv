webserv

A web server written from scratch: one poll() loop, no threads, no external libraries. Every socket, parser and child process is managed by hand.

From the command line

Upload a file, then remove it:

curl -F "file=@notes.txt" http://127.0.0.1:8080/uploads/

curl -X DELETE http://127.0.0.1:8080/uploads/notes.txt

Send a chunked body:

curl -H "Transfer-Encoding: chunked" -d @notes.txt http://127.0.0.1:8080/cgi-bin/echo.py
